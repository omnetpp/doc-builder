Getting Started
===============

The action builds the documentation website of an OMNeT++ model project into a
directory, and by default uploads it as the GitHub Pages artifact. These pages
show how to set it up, from the NED reference alone to a Sphinx site with the
C++ API and PDFs.

.. only:: html and not variant

   These pages are also a PDF, `doc-builder.pdf <../doc-builder.pdf>`__,
   built with the site (see :doc:`pdf`).
