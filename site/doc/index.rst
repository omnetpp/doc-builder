OMNeT++ doc-builder
===================

.. only:: variant

   .. note::

      This is a variant of the site, built from the same sources with other
      settings (see :doc:`config/variants`).

doc-builder builds the documentation website of an `OMNeT++
<https://omnetpp.org>`__ model project, ready for GitHub Pages, with the
toolchain of `docs.omnetpp.org <https://docs.omnetpp.org>`__ and
`inet.omnetpp.org <https://inet.omnetpp.org>`__:

*   the **NED reference** of the project's NED and MSG files, generated by
    ``opp_docgen``;
*   optionally a **Sphinx site**, the hand-written documentation that the NED
    reference becomes part of;
*   optionally the **C++ API**, generated by doxygen, linked from the pages of
    the NED types;
*   optionally **PDFs** of the Sphinx site.

It is a GitHub Action, ``omnetpp/doc-builder``, which runs the build in the
``ghcr.io/omnetpp/doc-builder`` container image. The same build runs on your
machine, too.

This site is an example of what it builds
-----------------------------------------

This site is built by the action from the `site/
<https://github.com/omnetpp/doc-builder/tree/v1/site>`__ directory of its
repository, which is a small model project: a source, a queueing node and a
sink. Its pages are the documentation of the action; the :doc:`NED Reference
<ned/index>` and the :doc:`C++ Reference <api/index>` are those of the model.

The tabs of the site show the ways the tabs can be navigated:

*   **Home**, this page, opens no menu;
*   **Getting Started** opens its pages as a menu, and has the navigation
    sidebar on the left;
*   **Configuration** is navigated by its menu alone, without the sidebar;
*   **Reference** has the trees of the NED reference and the C++ API in the
    sidebar.

:doc:`config/navigation` tells which settings do this, and
:doc:`config/variants` shows the site with settings that apply to all tabs.

Where to start
--------------

*   :doc:`guide/installation`: publish the NED reference of your model with a
    workflow of a dozen lines.
*   :doc:`guide/sphinx-site`: make it part of your own Sphinx documentation.
*   :doc:`config/inputs`: everything the action can be told.
